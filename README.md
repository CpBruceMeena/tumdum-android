# TumDum - Food Delivery App

A Flutter-based food delivery application similar to Swiggy, designed to provide a seamless food ordering experience.

## Features

- Modern and intuitive user interface
- Restaurant browsing and menu exploration
- Custom fonts using Poppins font family
- Responsive design for various screen sizes

## Prerequisites

- Flutter SDK (>=3.0.0)
- Dart SDK
- Android Studio / VS Code
- Android SDK for Android deployment

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/tumdum-android.git
   cd tumdum-android
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```
